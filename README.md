# Прошивка Xiaomi Smart Band 8 с Mac (CN → Global)

*Flash a Chinese Xiaomi Smart Band 8 to global firmware over Bluetooth LE from a Mac, no phone needed.
Documentation is in Russian.*

Скрипт `miband8_flash.py` подключается к браслету по Bluetooth LE прямо с MacBook,
авторизуется ключом от аккаунта Xiaomi и загружает файл прошивки тем же протоколом
обновления, что используют Mi Fitness и Gadgetbridge. Протокол перенесён из исходников
[Gadgetbridge](https://codeberg.org/Freeyourgadget/Gadgetbridge) (AGPLv3).

## Прочитайте до начала

- **Проверено на одном настоящем браслете:** M2239B1 с китайской 1.8.124 прошит на глобальную 2.3.14
  командой `flash --announce-version firmware.bin`: первые 40% файла в обычном режиме (больше 14 часов),
  остальные 29 МБ с `--fast --retry 10` примерно за 4 часа и 29 автоматических переподключений. Через минуту после 100% браслет перезагрузился, ещё около
  7 минут устанавливал прошивку и стёр сопряжение с Mac. Начните с безопасной команды `info`: если она
  работает, протокол совпадает.
- **Gadgetbridge разбирает формат файла прошивки только для Band 8 Pro.** Для обычного Band 8
  протокол загрузки тот же, но версию прошивки, скорее всего, придётся указать вручную
  (`--version`).
- **Риск.** Прошивка чужого региона официально не поддерживается: Xiaomi предупреждает, что
  браслет может перестать работать, гарантия теряется. Сообщество делает CN → Global через
  модифицированный Mi Fitness на Android, то есть браслет такую прошивку по Bluetooth принимает,
  но гарантий нет.
- **Версия с NFC.** Если у вас китайский браслет с NFC, глобальная прошивка (без NFC) может его
  отключить. Не прошивайте, пока не найдёте подтверждения от владельцев именно такой версии.
- **Прошивку скрипт не скачивает.** Нужен файл `.bin` официальной глобальной прошивки
  Xiaomi Smart Band 8 для вашей модели (`info` покажет модель).

## Что понадобится

1. MacBook с Bluetooth и Python 3.9+ (`python3 --version`).
2. **Ключ авторизации** (auth key, 32 hex-символа). Без него браслет не пустит.
   На Mac его можно получить утилитой
   [Xiaomi Cloud Tokens Extractor](https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor):
   запустите её, войдите в аккаунт Xiaomi, к которому привязан браслет (для китайской версии
   обычно сервер `cn`), и найдите в списке BLE-устройств ключ для Smart Band 8.
   Ключ меняется при каждой новой привязке к Mi Fitness, поэтому после получения ключа браслет
   не перепривязывайте.
3. Файл глобальной прошивки `.bin`.
4. Заряд браслета не меньше 50%, лучше держать его на зарядке.

## Установка

```bash
git clone https://github.com/kostenpavel1/miband8-cn-to-global.git
cd miband8-cn-to-global
python3 -m venv .venv
source .venv/bin/activate
pip install --upgrade pip
pip install -r requirements.txt
```

Обновить pip обязательно: со старым pip из macOS не собирается зависимость `pyobjc-core`.

При первом запуске macOS спросит, можно ли Терминалу использовать Bluetooth: разрешите.
Если окна не было, откройте «Системные настройки → Конфиденциальность и безопасность → Bluetooth».

## Порядок действий

1. **Выключите Bluetooth на телефоне.** Браслет виден, только пока он не подключён к телефону.
2. Найдите браслет:
   ```bash
   python miband8_flash.py scan
   ```
3. Проверьте ключ и посмотрите сведения. Эта команда ничего не меняет:
   ```bash
   python miband8_flash.py info --key 0x0123456789abcdef0123456789abcdef
   ```
   Должны появиться «Авторизация успешна», модель, текущая версия прошивки и заряд.
4. Прошейте. `caffeinate` не даст Mac уснуть во время загрузки:
   ```bash
   caffeinate -i python miband8_flash.py flash --key 0x0123456789abcdef0123456789abcdef global.bin
   ```
   Скрипт покажет модель, текущую и новую версию, md5 файла и попросит ввести `YES`.
   Если версия не определилась из файла, он предложит похожие строки; укажите версию явно:
   `--version 2.3.14` (подставьте свою).
   Если браслет отказывается начинать установку (`status=6` на китайской 1.8.124), можно сообщить
   ему другую версию, как это делает Mi Fitness при переходе CN → Global:
   `--announce-version firmware.bin`. Файл и его md5 при этом передаются настоящие.

   С Mac загрузка очень медленная: около 0,4 КБ/с, то есть файл на 50 МБ грузится больше суток.
   Дело в браслете: через 20 секунд после подключения он переключает связь на интервал 150 мс
   (это видно в системном логе Bluetooth на Mac), а повлиять на это со стороны Mac нельзя.
   В строке загрузки видна скорость в КБ/с.

   Для долгой загрузки добавьте `--retry 10`: при обрыве связи скрипт подождёт 30 секунд,
   переподключится и продолжит с места остановки, не спрашивая `YES` повторно. 10 — это сколько
   попыток подряд он сделает, если загрузка совсем не двигается; после каждого успешного куска счёт
   начинается заново. Отказы браслета (неверный ключ, `status=N`) он не повторяет.

   Флаг `--fast` (экспериментальный) шлёт пакеты прошивки без подтверждения каждого, как телефон.
   Скорость растёт до 1,5–2,5 КБ/с, но на M2239B1 с CN 1.8.124 браслет в этом режиме 3 раза из 3 зависал
   через 1–2 минуты и разрывал связь. Загруженное при этом не терялось, но пользоваться им не советую.
   Если всё же решите, `--fast --retry 10` будет переподключаться после каждого зависания сам:
   с учётом пауз на перезапуск браслета выходит примерно 1–1,5 КБ/с против 0,7 КБ/с в обычном режиме,
   ценой десятков, а то и сотен зависаний браслета за загрузку.
5. После 100% браслет сам проверит файл, установит его и перезагрузится. Не трогайте его
   до конца. Дальше, как описывает сообщество: сбросьте браслет, в Mi Fitness выберите
   регион не «Китай» и привяжите браслет заново. После перепривязки ключ авторизации будет новым.

## Если что-то пошло не так

| Сообщение | Что значит |
|---|---|
| `Bluetooth недоступен для этой программы` | У программы, из которой запущен скрипт, нет доступа к Bluetooth. Запускайте из приложения «Терминал» и разрешите ему Bluetooth. |
| `Xiaomi Smart Band 8 не найден` | Браслет подключён к телефону или далеко. Выключите Bluetooth на телефоне. Если браслет есть в «Системные настройки → Bluetooth» как подключённый, скрипт должен подхватить его сам; если нет, нажмите там у браслета ⓘ → «Забыть это устройство». |
| `Неверный ключ авторизации` | Ключ не тот или устарел после перепривязки. Получите заново. |
| `Браслет отказался начинать установку (status=N)` | Браслет видел только версию и md5, файл не передавался. Попробуйте полный заряд, затем `--announce-version firmware.bin`. |
| Обрыв во время загрузки | Запустите `flash` ещё раз: браслет сообщит, сколько уже получил, и скрипт продолжит с этого места (так же делает Gadgetbridge). С `--retry 10` скрипт сделает это сам. |
| Загрузка идёт часами | С Mac это нормально, см. выше про интервал 150 мс. |
| `похоже, он завис в быстром режиме` | Подождите минуту, пока браслет перезапустится, и запустите `flash` без `--fast`: загрузка продолжится с места остановки. |
| `браслет не ответил` | Попробуйте `--max-write 180` или поднесите браслет ближе. |

Флаг `-v` включает подробный лог с hex-дампами всех пакетов: с ним проще разбираться в проблеме.

## Если есть Android-телефон

Путь, который чаще всего описывает сообщество: модифицированный Mi Fitness на Android
устанавливает глобальную прошивку через своё меню обновления. Gadgetbridge (из F-Droid) работает
с Band 8 по тому же протоколу, но файлы прошивки распознаёт только для Band 8 Pro, поэтому файл
для обычного Band 8 он может не принять.

## Тесты

`tests/loopback_test.py` гоняет скрипт против программной модели браслета: авторизация, шифрование,
передача частями, загрузка файла, `--fast`, продолжение загрузки и `--retry`. Браслет не нужен:

```bash
python tests/loopback_test.py
```
